# Billing Policies

## Billing cycle
Bills are generated on an approximately 30-day cycle matching the customer's billing period.
Usage is metered in kWh and billed according to the customer's enrolled rate plan (see Rate
Schedules).

## Common causes of a higher bill
1. Increased usage — more appliance or HVAC load, more occupants, or a longer billing period
   than usual.
2. A seasonal change affecting heating or cooling load.
3. A rate-plan mismatch — a customer's usage pattern may no longer fit their enrolled plan (for
   example, Time-of-Use is unfavorable for consistent daytime usage).
4. An estimated, non-actual meter read catching up to true usage in a later cycle.

## What representatives should do
1. Retrieve the customer's current and previous bill and usage.
2. Compute the percentage usage change.
3. If usage increased by more than 15%, usage growth is very likely the primary driver — state
   this plainly with the actual numbers.
4. If usage is flat or decreased but the bill still increased, check for a rate-plan change,
   seasonal rate adjustment, or added fees. Do not guess: if the cause isn't visible in the
   retrieved bill or rate data, tell the customer to request a formal bill review.

## What not to do
Never state a specific dollar cause — for example, "this $40 increase is from your air
conditioner" — unless it's directly derivable from the retrieved usage and rate data. General
education about what drives usage is fine; an unverified specific claim is not.
